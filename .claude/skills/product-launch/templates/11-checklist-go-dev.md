# Template — Checklist go-dev

> Étape 11 du skill `product-launch`. Avant de démarrer le développement (Bubble, Airtable, etc.), valider tous les points ci-dessous.

---

## Documentation
- [ ] Journal des arbitrages tenu à jour (toutes les décisions structurantes)
- [ ] Page Sécurité & RGPD rédigée (données personnelles, règles de visibilité)
- [ ] Documentation de passation rédigée
- [ ] Prompt Lovable conservé et documenté

## Produit
- [ ] Problem Statement rédigé et validé
- [ ] Personas définis (min. 1 persona principal)
- [ ] PRD rédigé avec objectifs mesurables
- [ ] User Stories Must rédigées avec critères d'acceptation
- [ ] Hors scope explicitement documenté

## Données
- [ ] Cycle de vie de chaque objet clé défini (statuts + transitions)
- [ ] Schéma BDD rédigé (objets, relations, tables pivot)
- [ ] Champs RGPD identifiés
- [ ] Cohérence statuts cycle de vie ↔ champs BDD vérifiée

## Sécurité & rôles
- [ ] Rôles utilisateurs définis
- [ ] Matrice de permissions rédigée
- [ ] Règles de visibilité des données personnelles documentées

## Périmètre
- [ ] MoSCoW complété
- [ ] Parcours principal de bout en bout décrit
- [ ] Won't documentés avec justification

## Technique
- [ ] Stack technique définie et justifiée
- [ ] Dépendances externes identifiées (APIs, outils tiers)
- [ ] Limites techniques anticipées documentées
