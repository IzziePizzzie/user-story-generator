# Validation d'un micro-outil avant build

## Étapes obligatoires

### 1. Recherche SEO
Chercher sur Google les requêtes exactes que les utilisateurs tapent pour ce besoin.
- Volume estimé (élevé / moyen / faible)
- Intention de recherche (outil gratuit ? tutoriel ? définition ?)
- Résultats actuels : sont-ils de bonne qualité ?

### 2. Analyse concurrentielle rapide
- Existe-t-il déjà 3+ outils qui font exactement ça ?
- Ces outils sont-ils bien designés ?
- Y a-t-il une UX médiocre = opportunité ?

### 3. Critères de validation
Un produit est validé si :
- [ ] Volume de recherche détectable (même faible mais ciblé)
- [ ] Les outils existants ont une UX mauvaise ou une friction élevée
- [ ] Peut être construit en moins de 2 jours
- [ ] Monétisable (freemium ou affiliation évidente)

### 4. Output attendu
Fournir un résumé en 5 lignes :
- Opportunité : oui / non / incertain
- Raison principale
- Risque principal
- Recommandation : build / ne pas builder / tester d'abord
