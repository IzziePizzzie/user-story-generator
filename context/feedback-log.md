# Feedback & Learnings Log

Ce fichier centralise tous les retours reçus (utilisateurs, communautés, tests perso) et les règles qui en découlent.

---

## Format d'entrée

```
## [DATE] — [SOURCE] — [Produit concerné ou "Global"]
**Feedback** : ce qui a été dit ou observé
**Règle / apprentissage** : ce que ça change dans ma façon de travailler
```

---

## Règles déjà établies (avant lancement)

### R001 — Pas d'inscription avant la valeur
**Source** : Best practices UX + persona research  
**Règle** : Aucun outil ne demande une inscription avant que l'utilisateur ait vu le résultat principal.

### R002 — Résultat en moins de 30 secondes
**Source** : Persona research  
**Règle** : L'utilisateur doit obtenir une valeur visible en moins de 30 secondes après son arrivée sur la page.

### R003 — Interface soignée = différenciateur clé
**Source** : Analyse concurrents  
**Règle** : Chaque outil doit avoir une interface que je serais fier de montrer dans mon portfolio design.
